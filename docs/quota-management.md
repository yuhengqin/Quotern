# 订阅额度管理

主窗口与 macOS / Windows 托盘面板共用额度管理状态，Windows 宠物也复用这份读数。额度来自既有订阅读取器，Token 与费用仍由 Core 本地统计链路计算。

CLI 浏览器面板也提供同一套卡片、详情、趋势和手动刷新。CLI 可独立读取现有 13 个订阅通道（含 Gemini CLI），无需运行 Quotern Desktop；仍需各 Agent 自身的有效登录状态，依赖 Agent 客户端/CLI 的来源保留原要求。网页显示的是提供 HTTP 服务的那台机器的额度。网页在可见时每 15 秒读取本地快照，回到页面时更新；上游读取仍受管理器间隔和退避约束。

额度采集、归一化、历史和分析位于 `packages/core/src/quota`。Desktop 保留 Electron 网络适配、IPC、系统电源事件与通知；CLI 使用 Node 网络，当前不发送系统额度通知。Desktop 运行时，CLI 的 observer 仅在网页请求或手动刷新时读取额度，不启动额外额度轮询。

## 查看与设置

- 点击 Windows / macOS 托盘图标打开概览；右键菜单仍提供主窗口、同步、设置和退出。概览失焦或按 Esc 关闭，内容超过屏幕高度时内部滚动。
- 一张卡显示一个通道，默认保留名称、套餐、前三个额度窗口与重置/到期时间；时间窗口按月、周、日、小时从长到短排序，独立模型额度保留原有次序。剩余额度显示在进度条右侧，周期使用「5 小时限额」「周限额」「月限额」「日限额」等中文说明，模型分组明确显示为「Opus 模型周限额」。Cursor 两个模型池显示为「Cursor模型额度」「其他模型额度」。至少两个窗口且全部已知的实际重置时间戳完全相同时，在套餐下显示一次「统一重置」；时间不同、未知或包含到期窗口时仍逐项显示，不按相同的分钟文案推断。重置次数在套餐旁显示为「可重置 3 次」。只有状态说明的来源使用紧凑状态卡，保留名称和原因；状态行预留两行文字高度，同排卡片拉齐，避免重试按钮造成高度跳动。有效分析默认最多一行，优先展示耗尽估算，其次节奏；完整窗口与可交互趋势收在详情弹窗。点击整张卡片打开详情弹窗；悬停时高亮并延迟显示「点击查看详情」，键盘聚焦也会提示，Enter / Space 可打开。拖选文字与点击重试不会打开弹窗。
- 详情显示读取来源、数据观察时间、账号归属、最近查询与手动刷新。今天显示时、分，其他日期显示日期。查询完成后更新时间，包括失败或返回旧读数的情况；观察时间仍取数据本身的时间，用于历史与预测。同一分钟内多次查询的显示文字相同。进度条颜色和剩余百分比表达接近上限，0% 表达当前窗口耗尽；读数过旧、登录失效、组织共享池耗尽等额外状态保留，临时读取失败时可就地重试。旧数据不会生成当前耗尽预测，供应商未提供窗口或比例时不补造零值。
- 已接入官方状态页的来源在详情中显示整体服务状态：绿色「服务正常」、黄色「轻微异常」、橙色「严重异常」、红色「重大故障」、蓝色「维护中」。轻微异常与维护状态收在标题旁的状态点，悬停或键盘聚焦查看说明；严重异常或重大故障同时显示完整提示。正常状态收在详情中。获取失败或结果过期时显示灰色「状态未确认」，保留原检查时间。悬停或键盘聚焦可查看说明和检查时间，点击打开官方状态页；具体产品与地区的影响以官方页面为准。只有配置了官方状态页的来源才轮询和显示。
- Desktop 设置 → 订阅可分别关闭接近上限提醒、恢复提醒、微型趋势，选择均匀 / 工作日 / 历史习惯参考节奏，或关闭通道。关闭通道同时暂停它的后台读取和提醒。
- Dashboard 和 Desktop 的「监控目录」自动读取默认目录，可额外添加最多 20 个已登录的 Codex home / Claude 配置目录，并编辑、移除或分别关闭监控、提醒。这里不执行登录或账号切换；同一目录切换登录后，后续读数跟随当前账号。新建、改路径或重新启用时按规范路径拒绝重复目录及默认目录；旧重复配置仍可移除或暂停。每个 profile 使用独立 reader 与缓存；变更配置会废弃旧请求结果。目录属于提供服务的本机，设置保存目录和备注，不复制认证文件。原有 Token / 会话采集目录配置保持独立；添加额度 profile 不会改变历史 Token 桶的采集范围。
- 目录列表显示读取状态与已核实的匿名账号标识；不同来源识别为同一账号时给出提示。同一通道、同一已核实账号的新鲜成功额度卡片只显示一份，优先观察时间较新的读数，同时间优先原生来源；失败、陈旧或身份未知的来源保持独立显示。合并仅影响展示，不合并配置、修改历史或停止监控。

## 多来源额度

OMP 的 `~/.omp/agent/agent.db` 中 `usage_history` 可自动发现多个订阅账号并列显示（可用 `QUOTERN_OMP_AGENT_DB` 指定数据库，或 `OMP_AGENT_DIR` 指定 agent 目录）。只读取窗口投影，不读取 `auth_credentials.data`。OMP 卡片标注本地记录与实际观察时间，缺少账号证据时注明未核实，过 30 分钟标记陈旧；独立观察卡不发额度通知或写账号分析历史。

官方读数与 OMP 记录只有在账号精确匹配、窗口词汇已知且本地观察更晚并仍在 30 分钟内时才替补。Claude 同时核对邮箱与组织，不做子串匹配；Codex primary/secondary 是序号，必须有明确 window_label 才确定时长。不同刷新批次的窗口不拼成同一个新快照。未登录或账号冲突不借用；旧的 OMP 不能覆盖较新的官方陈旧快照；原请求的 Retry-After 继续约束轮询。来源本身的时间与完成本机查询的时间分别保留。

## 提醒与分析口径

Gemini CLI 保留有效的 model/tokenType 窗口和服务端重置时间，不合并模型池或推测固定日周期。当前协议未提供周期长度，也未提供可验证的账号归属，因此该渠道只展示额度，不生成趋势、耗尽预测或阈值通知。认证与版本边界见 [Gemini CLI](subscription-plan-design.md#gemini-cli)。

5h 等短周期在已用 90% 时提醒；长周期在 70% 和 90% 时提醒。首次观察、账号变化、重新启用通知或通道时建立新基线，不补发旧提醒；同一周期每个阈值各提醒一次。利用率回调不重新触发阈值。只有供应商重置时间推进且消耗明显下降时才发送恢复提醒；套餐到期不当成额度重置。

节奏在界面显示为「使用较慢」「使用偏快」「节奏正常」，悬停查看「当前已用 X%，按当前周期进度预计使用 Y%」及工作日/历史习惯等实际参考依据。内部仍以参考曲线与已用比例之间的百分点差值计算，不代表近期消耗速度或耗尽时间。工作日按系统本地日历的周一至周五计算，短于两天的窗口仍按均匀节奏。自动参考曲线需要近 28 天内至少 14 个不同日期的观察，否则退回均匀；长时间未观察的增量不会直接全部归到醒来的那一天。

耗尽预测使用近 90 分钟的有效额度样本，至少三条且跨度至少 30 分钟，斜率为正、预计耗尽早于已知重置时刻时才生成。最新样本过旧、账号身份不明、窗口已耗尽、周期变化或缺少重置证据时不生成预测。展示时，在已知同一账号/功能的限额范围内只保留最早一条，不跨相关窗口重置或已耗尽池外推；短周期重置未知时不展示其长周期预测。长周期余额可能先耗尽，因此不固定只显示最短周期。Codex 附加功能和独立模型池分别判断；未知范围不凭相同名称或重置时间合并。此筛选仅影响卡片与详情，不删除历史、修改原始分析或阈值通知。同一额度池的多个周期仅在最短周期显示趋势，卡片摘要与详情使用同一规则；最短周期采样不足时不回退到长周期。独立模型与功能额度池分别保留各自的最短周期趋势，后台仍完整记录各窗口历史。详情中的趋势图高 36px，保留 0–100% 纵轴，显示最近六小时的有效样本，支持鼠标与左右方向键查看；采样不足三条时不画线。

Copilot 的 Code completions 显示为「代码补全」。仅当实际快照明确返回聊天与代码补全都无限时，合并为「聊天与代码补全 · 无限」；有限、未知、缺失或共享池耗尽不合并。当前付费套餐的 Chat 消耗 AI Credits，代码补全无限，Free 补全有限额；不按套餐名称猜测权限，见 [GitHub 官方计费说明](https://docs.github.com/en/copilot/concepts/billing-and-usage/individuals/billing)。旧版快照的双无限权益仍可正确展示。

OpenCode Go 保留五小时、周、月三种窗口，兼容官方 `usage.rolling/weekly/monthly` 与早期 `rollingUsage/weeklyUsage/monthlyUsage` 响应；官方百分比 1 表示已用 1%。月重置以接口时间为准，上游没有给出确切周期长度时不假设 30 天，因此月窗口可显示读数与趋势，但不生成依赖周期长度的节奏判断。Antigravity 保留全部有效模型池，卡片前三条、详情全部，耗尽模型也参与风险判断。

## 数据、刷新与故障

主进程维护一套采样器，不依赖窗口或宠物是否可见。基础读取间隔：Codex 3 分钟，Claude / Cursor 等 5 分钟，Antigravity 10 分钟，Copilot 15 分钟。交互后较频繁，空闲后降低频率；锁屏或电池模式进一步降低，最大周期 30 分钟。手动刷新会发起查询，进行中的同来源请求合并，按钮在等待期间禁用；恢复/解锁后延迟五秒重新尝试。网络源的 Retry-After 被保留到调度层，未提供时逐步退避。

Desktop 使用独立的内存 Chromium session 读取额度，沿用系统代理。明确的连接关闭、重置、网络变化或网络挂起错误会合并重建代理配置与连接，并对 GET / HEAD 最多重试一次，沿用原请求的超时与取消信号；HTTP 401 / 403 / 429 和证书错误不走连接重试。连接重建等待同 session 的在途读取结束，不影响渲染器或更新服务。恢复/解锁先重建该网络 session，随后可越过本地失败退避尝试一次，但仍遵守服务端 Retry-After。

历史保存在 Electron `userData/quota/history.json`，设置在同目录的 `preferences.json`。开发模式位于本 worktree 的 `.quotern-dev/electron/` 下。历史只保存不可逆账号键、来源、窗口身份、时间、百分比和重置时间，保留 90 天；不保存令牌或原始供应商响应。凭据指纹与历史账号键分离，稳定账号 ID 优先；只有不透明凭据时保守使用指纹，凭据更新可能开启新的历史序列。无法确认账号的本地引擎只显示当前额度。

CLI 将额度历史与设置保存在其数据目录的 `quota/` 下（正式运行默认 `~/.quotern/quota/`，隔离开发为 `.quotern-dev/data/quota/`）。两端不共享这两个可写文件，也不自动迁移对方的偏好和历史，避免同时运行时互相覆盖。

两端另将安全查询快照发布到 Core dataDir 下的 `quota-snapshots/cli.json` 和 `desktop.json`，按 runtime 分文件串行原子替换；Desktop 使用 `resolveDataDir()`，同样遵守开发隔离。`quotern quota` 与 `quotern mcp` 只读这些文件，既不打开偏好/历史 store，也不触发网页 GET 所带的交互刷新。默认选最近生成的有效文件；文件上限 1 MiB，读坏文件不修复。观察时间和文件生成时间分别校验 30 分钟新鲜度，已重置窗口清除预测。查询命令和 JSON 语义见 [CLI 文档](../CLI.md#额度查询与只读-mcp)。

`quota diagnostics` 将本次读取的固定阶段、HTTP 状态及错误码导出。通用 HTTP 层记录网络和限流，Codex/Claude/Gemini 另外记录认证与解析阶段；其余 reader 的未细分失败使用 `UNAVAILABLE`，不声称已重建所有内部尝试。`retainedFrom` 区分缓存保留和 OMP 替补，来源是实际展示数据的来源；native 失败后采用 OMP 时仍保留先前失败轨迹。`retryAt` 是后台失败退避时间，手动刷新仍沿用现有可主动重试规则。

CLI 的 Node 网络与 Desktop 的 Chromium 网络配置不同。若网络需要代理，已设置 `HTTP_PROXY` / `HTTPS_PROXY` 仍可能不足；使用 Node 24 时，在启动 CLI 的同一终端先设置 `NODE_USE_ENV_PROXY=1`（PowerShell：`$env:NODE_USE_ENV_PROXY = '1'`）。这让 Node 的 `fetch` 使用已有环境代理，不会修改系统代理，见 [Node 官方说明](https://nodejs.org/docs/v24.0.2/api/cli.html#node_use_env_proxy1)。该开关不适用于所有早期 Node 版本。

写入采用串行原子替换。设置读取失败时暂停提醒并拒绝覆盖未知设置；保存失败不应用新选择。历史写入失败会提示，但不阻断当前额度展示。临时失败只在确认同账号时沿用旧值；账号切换或身份未知时清除旧账号展示与分析。

具体数据源限制及只读凭据边界见 [订阅数据说明](subscription-plan-design.md)。系统通知能否送达还取决于操作系统、应用打包身份与用户通知设置。

## 上游协议复核

`scripts/upstream-contracts.json` 记录依赖字段、公开 npm 版本源与官方额度语义探针。`pnpm test:upstream-contracts` 只运行离线检查器测试；`pnpm check:upstream-contracts` 执行公开网络检查，输出位于 `.quotern-dev/upstream-contracts/`。版本变化、公开文案缺失及未建立验证基线都标为待复核，不等于协议损坏。网络失败单独失败，不关闭已有复核 Issue；定时 workflow 每周检查，只维护带机器标识的 Issue，相同正文不重复更新。当前验证版本保持未建立，需结合脱敏解析样例与实际来源版本人工复核后更新，自动任务不会推进基线。公开语义探针于 2026-10-16 核对，文案改写也可能触发复核。
