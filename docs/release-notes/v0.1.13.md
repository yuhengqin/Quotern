# Quotern v0.1.13

这个版本补充了更多 Coding Agent 的用量采集和订阅额度展示，并修复桌面端启动、便携版更新以及部分历史用量缺失问题。

## 🖥️ Desktop

- 主面板和托盘新增 Copilot 套餐剩余额度、内联建议与重置时间，按本机登录账号匹配，避免多账号混用。
- 新增 MiniMax Code、WPS 灵犀（WPS Comate）用量采集，MiniMax 额度卡支持新版桌面客户端与 mcode CLI。
- 修复 ZCode 额度卡在智谱账号下不显示；Codex 额度查询失败时展示原因和重试入口，未使用 ChatGPT 订阅时隐藏卡片。
- 修复静默启动后再次打开不显示窗口，以及原生崩溃后进程卡死、无法重新打开的问题。
- 修复 Windows 便携版自动更新后变成普通安装版的问题。
- 修复 OpenCode 2.0 新用量、CodeBuddy 整轮 Token 采集，以及休眠后缺失日期不显示的问题。
- WorkBuddy 使用官方品牌图标。

## 升级说明

Windows 便携版只提示新版本，请手动下载便携版更新。

## 📦 下载与完整记录

请从本页附件选择与系统匹配的客户端；Windows 便携版用户请选择便携版。

完整变更见 [Desktop CHANGELOG](https://github.com/yuhengqin/Quotern/blob/v0.1.13/apps/desktop/CHANGELOG.md)。
