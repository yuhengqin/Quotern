# Quotern v1.0.0

**你的 AI 用量，一处看清。** Quotern 将 Coding Agent 的 Token 用量、订阅额度、预估费用和会话记录集中到本地面板，提供 macOS / Windows 桌面客户端。

1.0.0 补齐了桌面端的安装与分发体验：Windows 提供可选目录与用户范围的安装向导，ARM64 和 x64 都有安装版、便携版；macOS 按 Apple Silicon 与 Intel 分包，均提供 DMG 和 ZIP。

## ✨ 功能概览

- **多 Agent 统一统计**：查看 Claude Code、Codex、Cursor、Gemini CLI 等工具的用量，按时间、Agent、模型和项目筛选，追踪输入、输出、缓存与费用趋势。
- **订阅额度监控**：集中查看已接入渠道的剩余额度、使用窗口和重置时间，并展示登录失效等读取状态；需要对应渠道的有效登录或配置。
- **会话浏览器**：搜索和筛选已采集会话，展开查看模型、Token、缓存、费用依据与任务时长；数据覆盖范围因来源而异。
- **桌面概览与宠物**：通过托盘和紧凑窗口查看核心读数，在设置中选择、预览桌面宠物并调整大小。
- **价格查询与分享卡**：查询模型费率、对比预估费用，将所选时段的用量制作成分享卡。

费用会区分来源报告金额、按模型费率估算和价格未知的情况，请勿将预估费用直接当作实际付款账单。

## 🛠️ 安装改进

- Windows 安装向导支持选择安装目录、当前用户或所有用户，默认勾选创建桌面图标和安装后打开应用；安装器支持中文、英语、日语和韩语。
- Windows ARM64 与 x64 分别提供独立的安装版和便携版，文件名包含系统、版本与架构。
- macOS Apple Silicon 与 Intel 分别提供 DMG / ZIP，本版采用 ad-hoc 签名和手动更新。

## 📦 下载说明

请在本页 **Assets** 中按系统与芯片选择文件。一般安装优先选择 macOS 的 `.dmg` 或 Windows 的 `-setup.exe`。

### 🍎 macOS（Apple Silicon / Intel）

| 设备 | DMG 安装包 | ZIP 归档 |
| --- | --- | --- |
| Apple Silicon（M 系列，ARM64） | `Quotern-1.0.0-mac-arm64.dmg` | `Quotern-1.0.0-mac-arm64.zip` |
| Intel Mac（x64） | `Quotern-1.0.0-mac-x64.dmg` | `Quotern-1.0.0-mac-x64.zip` |

> 本版 macOS 应用采用 ad-hoc 签名，**未经过 Developer ID 正式签名与 Apple 公证**；首次打开可能受到 Gatekeeper 拦截。

### 🪟 Windows（x64 / ARM64）

| 架构 | 安装版 | 便携版（免安装） |
| --- | --- | --- |
| x64（常见 Intel / AMD 电脑） | `Quotern-1.0.0-win-x64-setup.exe` | `Quotern-1.0.0-win-x64-portable.exe` |
| ARM64（Windows on ARM 设备） | `Quotern-1.0.0-win-arm64-setup.exe` | `Quotern-1.0.0-win-arm64-portable.exe` |

## 🔄 安装与更新

- **macOS 安装**：打开 DMG，将 Quotern 拖入「应用程序」；使用 ZIP 时，解压后将 `Quotern.app` 移入「应用程序」。如首次打开被拦截，确认来自本项目并核对校验和后，按 [Apple 官方说明](https://support.apple.com/en-us/102445)在「系统设置 → 隐私与安全性」中查看「仍要打开」选项。
- **Windows 安装**：运行 `-setup.exe` 按向导安装；便携版可直接运行对应的 `-portable.exe`。
- **手动更新**：本版 macOS 与 Windows 便携版需要手动下载对应架构的新版文件并替换；Windows 安装版保留应用内更新能力。
- **文件校验**：附件 `checksums-sha256.txt` 列出发行文件的 SHA-256 校验和，可用于检查下载文件是否完整。
