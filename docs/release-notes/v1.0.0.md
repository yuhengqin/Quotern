# Quotern v1.0.0

本版统一 Windows 与 macOS 的发行包，补齐安装向导、ARM64 支持和源码归档构建验证。

## 🖥️ Desktop

- 📦 Windows x64 与 ARM64 均提供安装版和便携版，文件名包含架构，便于选择对应版本。
- 📦 Windows 安装向导支持选择安装目录、当前用户或所有用户，默认创建桌面图标并在安装完成后打开应用；安装器支持中文、英语、日语和韩语。
- 📦 macOS Apple Silicon 与 Intel 分别提供 DMG 和 ZIP，使用 ad-hoc 签名，无需 Apple Developer 会员。
- 📦 发布流程检查各平台文件哈希、版本、架构和更新清单，并验证不含 `.git` 的源码归档能够安装依赖与构建。

## 升级与首次启动

- **macOS 包未经过 Apple 公证，仅支持手动更新。** 首次打开可能受到 Gatekeeper 限制，请参阅 [Apple 的打开应用说明](https://support.apple.com/102445)，确认来源后通过系统设置允许打开。
- Windows 便携版仅提示新版本，请手动下载对应架构的便携版更新。
- 本次只准备 GitHub Draft Release，尚未公开发布，也未向 npm 发布软件包。

| 平台 | 安装版 | 便携版或归档 |
| --- | --- | --- |
| macOS Apple Silicon | `Quotern-1.0.0-mac-arm64.dmg` | `Quotern-1.0.0-mac-arm64.zip` |
| macOS Intel | `Quotern-1.0.0-mac-x64.dmg` | `Quotern-1.0.0-mac-x64.zip` |

附件中的 `checksums-sha256.txt` 可用于核对文件完整性。Source code ZIP / tar.gz 为此 tag 对应的源码快照，构建步骤见 [CONTRIBUTING](https://github.com/yuhengqin/Quotern/blob/v1.0.0/CONTRIBUTING.md#从-source-code-归档构建)。

完整版本记录见 [Desktop CHANGELOG](https://github.com/yuhengqin/Quotern/blob/v1.0.0/apps/desktop/CHANGELOG.md)。
