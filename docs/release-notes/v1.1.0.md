# Quotern v1.1.0

这版扩充了订阅额度、会话详情和本地报表。你可以按 Claude Code 或 Codex 账号打开终端，在会话列表里追踪任务和费用，也可以用 CLI 把用量导出给表格或 Agent。

## 🖥️ Desktop

- 💄 外观设置新增 16 套可选样式，主窗口与托盘同步。支持动画的样式可按需开启和暂停装饰。[样式变更](https://github.com/yuhengqin/Quotern/commit/c849a537)
- 🆕 托盘显示紧凑的额度摘要，支持自定义唤起快捷键。额度和厂商服务状态提醒支持合并显示，也可以一次关闭当前提醒。[通知变更](https://github.com/yuhengqin/Quotern/commit/7e2221e3)
- ⚡️ 会话详情与性能分析在独立进程中运行，减少查询占用桌面主进程的时间。[性能变更](https://github.com/yuhengqin/Quotern/commit/5abdb300)
- 🐞 改善 Windows 桌宠置顶恢复，并在桌面热力图中加入 Agent 筛选。[桌宠修复](https://github.com/yuhengqin/Quotern/commit/a2ce9706) · [热力图变更](https://github.com/yuhengqin/Quotern/commit/33d0dfbb)

## 🌐 Desktop 与 Web 面板

- 🆕 会话浏览支持关联导航、分页和 CSV 导出，详情显示任务时长、模型用量和费用依据。已支持的 Agent 可从本机终端恢复会话。[会话详情](https://github.com/yuhengqin/Quotern/commit/6d8fcdd9) · [终端操作](https://github.com/yuhengqin/Quotern/commit/5740bd25)
- 🆕 可从已监控的 Claude Code 或 Codex 配置打开终端，并为后续启动选择默认账号。Claude 在验证额度耗尽后可选自动切换默认账号。Claude Extra Usage 和 Anthropic Console 账单可分别连接。[账号和账单变更](https://github.com/yuhengqin/Quotern/commit/6677a71b)
- 🔌 新增 Gemini CLI 订阅额度，额度卡按窗口显示剩余量、重置时间和耗尽预测。前往「设置 → 订阅」为已验证的账号调整提醒。[Gemini CLI 支持](https://github.com/yuhengqin/Quotern/commit/8ac07586) · [额度详情](https://github.com/yuhengqin/Quotern/commit/e7e385bc)
- 🆕 设置支持创建、验证本地备份并恢复到新目录，分享卡可选择画幅并导出图片。[备份与分享](https://github.com/yuhengqin/Quotern/pull/3) [@upgrading-ai](https://github.com/upgrading-ai)
- 📈 模型参考价以 models.dev 为主，LiteLLM 补齐同厂商直连费率，长期运行默认每 24 小时重新校验。价格详情可查看来源和核实时间。[价格变更](https://github.com/yuhengqin/Quotern/commit/2c07f7a7)

## ⌨️ CLI

- 🆕 `quotern usage` 支持按日、周、月、模型和项目导出用量，提供 JSON 与 CSV 格式。[报表变更](https://github.com/yuhengqin/Quotern/commit/939a1401)
- 🆕 `quotern quota` 和 `quotern mcp` 可读取 CLI 或 Desktop 的本地额度快照，查询状态、预测、诊断和账号建议。[额度工具](https://github.com/yuhengqin/Quotern/commit/8ac07586)
- 🆕 `quotern backup` 支持创建、校验和恢复本地备份。`quotern demo` 可导出匿名快照并启动只读面板。[备份变更](https://github.com/yuhengqin/Quotern/commit/939a1401) · [演示快照](https://github.com/yuhengqin/Quotern/commit/2055ce46)

## 📦 下载与升级

| 平台 | 安装版 | 便携版或 ZIP |
| --- | --- | --- |
| macOS Apple Silicon | `Quotern-1.1.0-mac-arm64.dmg` | `Quotern-1.1.0-mac-arm64.zip` |
| macOS Intel | `Quotern-1.1.0-mac-x64.dmg` | `Quotern-1.1.0-mac-x64.zip` |
| Windows x64 | `Quotern-1.1.0-win-x64-setup.exe` | `Quotern-1.1.0-win-x64-portable.exe` |
| Windows ARM64 | `Quotern-1.1.0-win-arm64-setup.exe` | `Quotern-1.1.0-win-arm64-portable.exe` |

- Windows 安装版支持应用内更新。Windows 便携版和 macOS 请下载对应架构的新包手动更新。
- macOS 包使用 ad-hoc 签名，未经 Apple 公证。首次启动如被 Gatekeeper 拦截，核对附件来源和校验和后，可查看「隐私与安全性」里的「仍要打开」选项。[Apple 官方说明](https://support.apple.com/en-us/102445)
- CLI 独立升版至 `0.2.0`，使用 `npm install -g quotern@0.2.0` 安装或升级，需要 Node.js 20.10 或更新版本。[CLI 使用说明](https://github.com/yuhengqin/Quotern/blob/v1.1.0/CLI.md)
- 附件 `checksums-sha256.txt` 可用于校验下载完整性。GitHub 的 Source code 附件提供此版本的源码快照。[源码构建说明](https://github.com/yuhengqin/Quotern/blob/v1.1.0/CONTRIBUTING.md#从-source-code-归档构建)
