# 成就与个人足迹设计

用户已批准 2026-10-14 对话中的设计，并要求全部系列、独立分支和 worktree 内直接实现。目标是个人记录与分享。

## 产品范围
- 顶部分享旁的成就入口、未读圆点、热力图旁的累计活跃入口；独立 /achievements 页面与返回用量页。
- 收藏页包含展示架（最多3枚）、最近获得、最多3个接近目标、完整分类收藏、个人纪录、年度足迹。
- 自动达成、永久保存；轻量合并提示后主动打开庆祝弹窗。首次历史导入合并提示。关闭不丢失，不过期。
- 同一系列折叠旧等级；可展开全部等级。月度章逐月收藏。
- 所有系列：初次记录；Token；会话；累计活跃；连续日；月度全勤；月活跃20日；预估费用；会话累计跨度；单Agent陪伴；多Agent足迹；项目长跑；个人纪录；年度足迹。
- 阈值：Token 1M/10M/100M/1B；会话10/100/1000；活跃7/30/100/365日；连续3/7/30/100日；费用$10/$100/$1000；跨度10/100/1000小时；单Agent30/100日；多Agent2/3/5种且每种至少3日；项目30/100日；月度全勤与20日活跃按自然月；纪录为最长连续、单月活跃；年度足迹按自然年。
- 连续7日与自然周全勤不重复设章。月度全勤章趣味称号“月度肝帝”。
- 费用和时长均有明确口径，不声称实际付款或人的专注时长。
- 分享支持单枚、展示架、年度卡；预览后下载/复制PNG。费用、项目名称默认隐藏，用户主动开启。没有公开排行榜或外部自动发布。

## 数据与持久化
- Core 负责规则与共享磁盘状态，HTTP与Desktop IPC使用同一 /functions/tud-achievements 契约。
- 独立读取所有已采集的去重queue与session元数据，不受用量页面7D/30D等筛选、内存收集下限影响。
- 活跃日为统计时区自然日Token>0；当前固定Asia/Shanghai。忽略未来、不合法日期、零量撤销桶。
- Session按source+sessionId去重，跨度为每个会话首末消息间隔之和，含闲置及并发；标注缺失来源。增加元数据读取接口供纯规则计算及达成日期推导。
- 原始项目路径已被Token聚合丢弃。项目系列使用会话采集新增的路径哈希身份（不持久化完整路径），先覆盖有明确cwd的Claude/Codex，旧会话缓存自动重扫补充。同名不同路径不得合并；仅标签而无路径的记录不能冒充唯一项目，界面说明覆盖范围。
- 成就状态写入独立版本化文件，proper-lockfile锁内重读合并，唯一临时文件+原子替换、Windows占用重试。损坏文件保留并报错，不静默清空。
- 解锁保存规则版本、首次观察时间、可推导的达成日期、数值/费用/范围快照。已解锁不因重扫、价格变动或日志删除撤回。
- 全历史回补可提前达成日期；不重新庆祝。未知精确达成时刻只显示日期/首次发现，不伪造时间。
- 已读与已通知分开。通知通过锁内claim最多一次跨客户端领取；默认启用轻提示，用户可关闭。用户打开详情才标已读。
- 最大展示3枚，API验证ID、解锁状态与参数；一项修改不覆盖并发解锁。GET核验最新源文件，不依赖worker通知后的内存应用时序。
- 月度全勤/年度章在周期结束后结算，允许晚同步按原始日期补发；月活跃20日可在达到时解锁。
- 个人纪录永久保留高水位；刷新纪录不重复创建徽章/反复提示。当前连续日允许今天尚未使用时延续至昨天。

## 界面与边界
- CLI与Desktop同步入口和路由；共享成就组件使用两端各自API适配，避免为Desktop引入HTTP依赖。
- 已读、关闭提示、展示架持久化共享。移动窄屏可操作，暗色适配、键盘和Esc可用、减少动态效果。
- 请求失败显式显示重试；数据缺失不展示为已确认0。没有用户数据时展示真实空态与锁定目标。
- 不添加生产演示数据、收费兑换、任务刷量引导、分析上报。
- 图形用代码原生SVG徽章，不引入位图生成、外部素材请求和新增依赖。

## 验收
1. 14个系列完整可用；阈值、跨日/跨月/闰年、历史回补、空记录、来源缺失有规则测试。
2. 重复同步/重启不会重复通知或丢失解锁；并发状态修改及损坏文件有真实磁盘测试。
3. Core共同API正确验证请求；端间共享状态且不受当前筛选影响。
4. 两端可打开、返回、过滤、展开、展示架选取、庆祝和PNG导出；窄屏/深色/键盘验证。
5. 全仓pnpm test、Desktop typecheck通过，独立审查后修复实质问题。分支不合并、不推送，交付可审阅结果。
