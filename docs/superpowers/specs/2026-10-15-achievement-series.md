# 成就系列聚合与项目归属

用户已确认：主页按 14 个系列聚合，详情保留 Agent、项目、月份及年份记录，统一各处名称；在现有 `codex/achievements` worktree 实现。

- 全部收藏每系列一张卡，主卡展示已获得记录数、最高等级和最近目标，不使用会随对象增加而下降的完成分母。
- 系列详情以紧凑记录行展示对象和各等级。Agent、项目可搜索；月度记录区分本月、已获得与已结束。每枚旧等级仍可查看、展示和分享。
- 最近目标每系列最多一项；最近获得、展示架、单枚详情、通知和分享使用同一名称：成就名 + Agent / 项目。月度、年度名称自带周期。
- 推荐展示架优先不同系列，用户可主动选择同系列的不同对象。
- 项目优先依据最近的 Git 仓库识别；同一仓库子目录、关联 worktree 归入共同仓库。独立 clone、同名目录不凭名称合并。
- 非 Git 目录以最近的明确项目配置根识别。普通工作目录作为待确认候选，不自动授予新的项目成就；允许确认、重命名、合并和忽略。项目合并按自然日去重，操作可撤回。
- 完整 cwd 不写入会话元数据或成就文件。使用稳定的本地身份哈希，保留旧 cwd 哈希作为归属迁移证据；无法补证的旧项目可由用户确认。
- 已获得成就永久保留。归属变化只投影合并同一项目同等级，保留达成日期和快照；旧状态、展示架与已读/通知兼容，撤回合并可还原独立记录。
- 公开分享项目名称和费用默认隐藏。Dashboard 与 Desktop 使用共享实现。

验收包括：14 系列聚合、同系列多对象与多等级详情、过期月记录、空数据、项目子目录/worktree/同名不同仓库、跨 Agent 同日去重、设置持久化及撤回、旧徽章不丢失/不重复提示，以及分享隐私和移动布局。
