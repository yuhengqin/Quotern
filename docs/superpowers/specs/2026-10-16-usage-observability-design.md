# 会话与额度可观测性

用户已选择实现参考分析中的六项能力，排除会话级缓存诊断，同时支持 Dashboard 和 Desktop。

## 数据边界

- Core 独立会话账本保存用量事件、最近上下文快照、计费服务与正面认证证据，不保存对话内容或凭据。保留现有 Token 桶和上传契约。
- 首批用量适配 Claude、Codex、OpenCode、Pi、OMP；其他来源显示覆盖缺口。Codex 累计计数取增量，流式消息按调用覆盖，fork 重放去重。
- 上下文只使用来源明确记录的容量；Claude 压缩后 postTokens 覆盖旧读数。最近活动不宣称正在执行。
- 会话贡献叫“本机 Token 消耗占比”，按当前日期及 Agent 筛选，并保留未归属用量。记录金额、价格估算、未知分别标注；不声称是账单。
- 计费服务来自显式 provider，订阅/API 模式必须有认证类型证据，缺失保持未知。

## 额度与账号

- 保留默认账号；可添加独立 Codex home 和 Claude config 目录，分别构造 reader、缓存及 generation。配置最多 20 项，账号私密身份仅作哈希联接，不返回认证材料。
- 官方读取与 OMP usage_history 为不同观察源。来源保留观察时间；严格账号匹配后才可替补，未知身份或冲突不得借用。OMP 多账号可独立并列显示，标注本地观察、过期与未验证身份，不冒充刚查询的官方值。
- 所有公开额度状态通过现有 HTTP 和 Electron IPC 契约消费；设置变更有校验、持久化、旧请求隔离及错误提示。

## 界面

两端提供同构会话区域：最近活动、上下文、Token 贡献、计费服务汇总。额度区域增加账号管理与来源说明，维持紧凑布局和键盘可达操作。加载失败保留旧值并标记陈旧。

## 协议变化

公共 npm 版本检查与脱敏解析测试分开。缺验证版本或版本变化产生待复核信号；网络错误为检查失败。定时 CI 只维护带固定机器标识的 Issue，指纹相同不重复更新，失败不关闭已有 Issue。

## 验收

覆盖累计增量、流式覆盖、压缩、fork、未知容量、无认证证据、账号冲突、陈旧观察、profile更新迟到请求、HTTP/IPC校验及网络失败。执行 Core/前端/桌面检查与隔离服务界面验收，明确真实账号端到端覆盖限制。
