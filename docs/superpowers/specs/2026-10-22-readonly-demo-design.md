# 演示数据导出与只读运行

用户已确认：以当前本机数据制作可交互演示，先完成导出和只读模式，云服务器部署后做；正常数据、客户端、服务和偏好不得受影响。

## 数据与命令

- `quotern demo export --out <snapshot.json> [--data-dir <source>]`：只读已采集的 queue、会话元数据、成就收藏及价格缓存，不采集、不修复配置、不获取 owner、不注册 Hook、不访问网络。默认源为正常数据目录，输出必须显式指定，拒绝覆盖和源目录内/父目录中的目标。
- 输出一个版本化 JSON：导出时间、冻结参考时间、覆盖范围、匿名统计桶、规范化会话事件/命名、最终成就快照、生效价格。用字段白名单重建所有嵌套结构，保留数量、时间、费用与质量/完整性标记。
- 每次导出生成独立随机映射：项目、会话、事件、请求、账号及 replay 等标识不可与源关联；跨文件等价关系保留，真实 Codex turn UUID 仍映射为 UUID。项目/会话名称统一替换为演示标签，未知字段、原始路径、正文、认证、游标、日志和图片排除。
- 读取前后检查输入文件指纹，发生并发变化时有限重试，失败保留源和已有目标。输出独占创建、权限 0600；快照不声称是原始日志之间的事务。
- `quotern demo start --file <snapshot.json> [--host 127.0.0.1] [--port 8253]`：必须指定演示文件，不回退正常目录；纯内存加载，拒绝不兼容或损坏格式。

## 服务与界面

- 演示启动独立 HTTP 服务，复用现有统计/会话投影；不调用正常启动、loadConfig、sync、quota、Hook、owner、后台定时器或磁盘聚合缓存。仅 GET/HEAD，其他方法在路由执行前统一返回 `DEMO_READ_ONLY`，未知接口不能落入正常运行入口。
- 成就 GET 返回导出时冻结的最终快照；分享背景返回空的服务器图库；额度明确不提供在线读数。API 不读取快照以外的目录，不挂载整个数据目录。
- 冻结参考时间和演示标记在 React 挂载前注入 HTML。普通 HTML 不注入，正常客户端默认行为不变。日期默认值、滚动窗口与相对时间按该参考时间计算，保留事件真实时间。
- 演示 UI 明确标记快照日期，隐藏同步/额度管理及服务器持久化入口；自动 ensure-range、成就 claim/seen 和旧分享背景迁移不发写请求。筛选、搜索、分页、展开、价格比较、内置分享卡和下载继续可用。演示浏览器偏好使用独立命名空间。
- 共享组件的新参数默认正常模式，Desktop transport/入口/数据与默认时钟不改变。

## 验收

1. 脱敏哨兵覆盖各层未知字段、路径、标题、项目、账号和凭据；数量/质量/请求计费和 fork/turn 语义保持。
2. 导出前后源文件内容与目录清单不变；覆盖、路径重叠、损坏、并发变化失败安全。
3. 服务读取所有展示端点并遍历写请求，源与演示文件不变，无 owner/Hook/缓存副作用，可与正常实例共存。
4. 演示浏览器加载、切日期、会话、成就、分享与 focus 不出现写请求；日期不随真实时间漂移，正常偏好不变。
5. 相关测试、完整仓库测试/构建、Desktop 类型检查及独立审查。不会自动提交、推送或部署。
