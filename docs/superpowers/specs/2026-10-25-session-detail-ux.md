# 会话详情阅读体验

用户已要求落实本轮评审发现的全部问题。沿用 React / HeroUI 的共享弹窗；不新增第三方 UI 依赖，不改变采集算法、计价规则或已有导出能力。

## 设计

- 一个标题，固定标题区和关闭入口，单一正文滚动区；主题沿用项目 foreground / muted / surface / separator / accent tokens。
- 优先呈现统计时间范围、用量范围、Token 总量和费用来源；本会话 / 线程合计切换联动 Token 构成与模型费用。
- 线程包含当前会话及全部已识别后代，拆分本会话、子代理、分叉、其他关联；未知费用保留已知小计，不能转成零。
- 吞吐和首 Token 等待仅针对本会话，各自显示样本数和解释；不声称任务成功或纯生成速度。
- 输入分为未缓存输入 / 缓存读取 / 缓存写入，输出总量包含推理并显示“其中推理”；缺失分类不能当成零。
- 模型行默认显示模型、服务档位、Token 与费用，展开保留请求数、分类、计价依据和未计价量。
- 活动、技术信息、数据说明折叠，摘要保留已知信息；0、未记录、不支持分开。恢复命令复制保持可达，完整命令、目录、账号、会话 ID 和精确值仍可查看及复制。
- Token 遵循单位偏好；金额沿用已确定的美元前缀和最多四位小数，避免与同期格式规范冲突。精确模式保留原始数值，极小非零不能显示成零。
- Dashboard 和 Desktop 共用实现。通知定位读取已采集历史并在新详情中自动定位；列表筛选不改变一个线程的统计成员。

## 取舍

继续使用既有弹窗并独立组织详情，避免列表行重复嵌套。右侧抽屉和独立详情页暂不引入。Core 仅补充安全的关联用量快照与实际查询范围，使通知定位和普通列表都能显示相同口径；UI 不二次猜测成员或复算计价。

## 验收

混合分叉/多层子代理、部分费用未知、无指标、缺 Token 分类、极小费用、长文本、中文/英文、浅/深色与窄窗口；保留原始功能，验证 Escape、焦点返回、折叠和范围切换。自动化覆盖聚合/格式契约；实际 renderer 验证视觉和交互。

## 用户复审定稿（覆盖上文冲突项）

1. 删除精确/简洁切换及更多操作，统一使用已保存 Token 偏好和美元最多四位小数；原始数据沿用列表 CSV 导出。
2. 固定操作区仅保留继续会话、打开文件夹、复制恢复命令、复制项目路径；动作与复制能力独立。
3. 模型核心明细直接表格展示，价格依据折叠；窄屏仅表格区域横向浏览。
4. 复制成功用短暂 Toast；动作失败保留可见反馈和重试能力。
5. 保留简短“所选期间用量”，时区放入数据说明，保持原有查询范围。
6. 用户明确要求删除会话信息中的会话 ID、项目路径及恢复命令展示和重复复制入口；顶部复制按钮满足需求。
7. 活动指标直接展示；会话信息与数据说明只显示折叠标题，删除重复摘要。
8. 默认仅本会话；存在后代时可切换含关联会话，联动总量、构成和模型。响应表现和活动仍为本会话。
