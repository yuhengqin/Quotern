# 会话详情阅读体验

用户已要求落实本轮评审发现的全部问题。沿用 React / HeroUI 的共享弹窗；不新增第三方 UI 依赖，不改变采集算法、计价规则或已有导出能力。

## 设计

- 一个标题，固定标题区和关闭入口，单一正文滚动区；主题沿用项目 foreground / muted / surface / separator / accent tokens。
- 优先呈现统计时间范围、用量范围、Token 总量和费用来源；本会话 / 线程合计切换联动 Token 构成与模型费用。
- 线程包含当前会话及全部已识别后代，拆分本会话、子代理、分叉、其他关联；未知费用保留已知小计，不能转成零。
- 吞吐和首 Token 等待仅针对本会话，各自显示样本数和解释；不声称任务成功或纯生成速度。
- 输入分为未缓存输入 / 缓存读取 / 缓存写入，输出总量包含推理并显示“其中推理”；缺失分类不能当成零。
- 模型行默认显示模型、服务档位、Token 与费用，展开保留请求数、分类、计价依据和未计价量。
- 活动、技术信息、数据说明折叠，摘要保留已知信息；0、未记录、不支持分开。恢复命令复制保持可达，完整命令、目录、账号、会话 ID 和精确值仍可查看及复制。
- Token 遵循单位偏好；金额沿用已确定的美元前缀和最多四位小数，避免与同期格式规范冲突。精确模式保留原始数值，极小非零不能显示成零。
- Dashboard 和 Desktop 共用实现。通知定位读取已采集历史并在新详情中自动定位；列表筛选不改变一个线程的统计成员。

## 取舍

继续使用既有弹窗并独立组织详情，避免列表行重复嵌套。右侧抽屉和独立详情页暂不引入。Core 仅补充安全的关联用量快照与实际查询范围，使通知定位和普通列表都能显示相同口径；UI 不二次猜测成员或复算计价。

## 验收

混合分叉/多层子代理、部分费用未知、无指标、缺 Token 分类、极小费用、长文本、中文/英文、浅/深色与窄窗口；保留原始功能，验证 Escape、焦点返回、折叠和范围切换。自动化覆盖聚合/格式契约；实际 renderer 验证视觉和交互。

## 用户复审定稿（覆盖上文冲突项）

1. 删除精确/简洁切换及更多操作，统一使用已保存 Token 偏好和美元最多四位小数；原始数据沿用列表 CSV 导出。
2. 固定操作区仅保留继续会话、打开文件夹、复制恢复命令、复制项目路径；动作与复制能力独立。
3. 模型核心明细直接表格展示，价格依据折叠；窄屏仅表格区域横向浏览。
4. 复制成功用短暂 Toast；动作失败保留可见反馈和重试能力。
5. 保留简短“所选期间用量”，时区放入数据说明，保持原有查询范围。
6. 用户明确要求删除会话信息中的会话 ID、项目路径及恢复命令展示和重复复制入口；顶部复制按钮满足需求。
7. 活动指标直接展示；会话信息与数据说明只显示折叠标题，删除重复摘要。
8. 默认仅本会话；存在后代时可切换含关联会话，联动总量、构成和模型。响应表现和活动仍为本会话。

## Token 表格合并补充

独立 Token 构成合入模型与费用表格：第一行是当前口径合计，其后逐模型展示，沿用八列及“输出（含推理）/其中推理”关系。合计读取当前口径汇总，不以可见模型反推总量或费用；缺明细保留未知，未分类 Token、缺少模型的 Token、未分配费用及分类说明仍可见。无模型明细也保留合计行，窄屏沿用表格横向滚动。

## 信息层级修订（覆盖上述合计与说明布局）

根据本轮截图反馈，单模型且与汇总完全一致时不显示合计；多模型或缺归属时在表尾用普通背景、顶部细分隔线展示合计，禁止整块灰底干扰表头圆角。standard/unknown 不生成标签或空白副行，保留非默认档位。正文只展示结果、操作与必要的短异常状态；统计口径、样本数量/时长、缺失指标、分类/价格/隐私解释移入对应标题旁的可点击帮助浮层。保留未知与零、已知小计的区别。

模型区提供“查看模型价格”入口，价格页新增可清除的会话模型集合筛选；使用来源和原始模型名进行保守身份解析，不以费用 fuzzy 匹配替代模型身份，未匹配时显示空结果或部分结果，不退回全目录。原价格依据仅在费用帮助中按需查看；当前参考价不被称为历史账单。现有 UI 规范是唯一现役规则来源，AGENTS 只强化引用；增加针对默认标签、重复合计和解释浮层的自动验收，保留真实页面视觉检查。

## 紧凑展示与保留原页面（覆盖会话信息折叠约定）

参考价入口统一为“查看模型参考价”，去掉箭头，在新标签页打开并保留原会话页面、弹窗和滚动位置。Desktop 使用独立价格窗口，沿用 IPC 读取 runtime 生效价格；只对白名单同 renderer 文档的 `/pricing` hash 开放 preload，窗口控制仅作用于对应窗口，其他链接继续沿用系统浏览器行为。

少量会话信息直接显示。任务时长只省略 recorded 的冗余后缀，估算/含估算保留，具体计时来源及等待、思考、工具执行等含义放在时长标签旁的帮助入口。关联会话去掉独立“查看该会话的已采集历史”行，改由原名称提供同一链接；角色与名称横向排列，长名称或窄屏允许自然换行，不改变 Token、费用或历史查询范围。

## 六项整体精简定稿

无模型明细时移除八列空表，以紧凑缺失状态替代，已知总量、费用、小计与分配说明继续可见或从相邻帮助查看。两个性能指标都无样本时合并空状态；单项缺失仍分别表达，有效零值保留。关联分组仅一个成员时直接显示名称链接、角色与其用量，多个成员保持可折叠汇总及完整列表。会话信息在宽屏使用双列，活动短指标宽屏三列、窄屏两列，保持长文本、极大数值及低高度窗口可读。

没有后代的普通详情不显示固定范围标签和无可选范围说明；存在后代但旧 runtime 缺少关联明细时保留降级说明和已有线程摘要。费用帮助合并重复账单提示；仅一个模型且至多一套价格证据时直接展示依据，多模型或多套证据继续折叠。保持正常表格、推理关系、零值、已知下界、未知、操作能力、复制、日期/范围语义及参考价新页行为。用户明确授权验证后提交、合回 `codex/session-insights` 并同步 5197 预览，不推送。
