# 会话详情信息精简

用户已在本次对话批准以下方案，直接实施。

- 用量与费用区域包含范围切换、摘要、归属及模型表。范围定义只保留“包含已识别后代（子代理与分叉）”这一边界。
- 响应表现和已记录活动始终读取本会话，归入一个“本会话活动”区域，不随用量范围切换重复标记。
- 费用帮助保留简短来源和影响金额理解的状态；完整模型匹配、费率、规则与假设移到模型表下默认折叠的“查看计算依据”。当前参考价继续使用既有价格页入口。
- 子代理展开列表按名称、角色、Token、费用四列呈现，数字右对齐；窄屏角色换到名称下，保留所有成员、历史链接和分叉身份。
- 期间帮助区分所选期间和通知的已采集历史，只显示范围与“北京时间（UTC+8）”；半小时归集等规则、活动证据限制、隐私说明分别保留按需访问。

## 方案取舍

采用区域分组与渐进披露。单纯缩短全部说明无法解决切换范围误解；直接删除计算依据会失去核对模型匹配与估算假设的能力。

## 约束与验收

Dashboard 与 Desktop 共用实现；四语言文案齐全，不改采集、聚合、价格和 API。保留零、未知、已知小计、缺失明细、样本数、活动覆盖和旧 runtime 降级。费用与 Token 沿用现有格式入口，单价使用公共单价格式。

运行两端类型检查、Dashboard 测试、本地化检查、两端构建与现有 session-detail-ui 合成界面验收，查看宽屏、窄屏和展开后的截图。不得停止其他会话服务。无需发布、推送或修改真实数据。
