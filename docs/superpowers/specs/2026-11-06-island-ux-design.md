# Quotern 七项现有能力优化

用户选择了 codex-island 对照报告中「已有能力」表的七项优化。本次在 `069955a0` 上实现，保持已有采集、分析、分享、备份与完整详情可访问。主代理负责实现和集成；子代理仅做有界调查和最终独立审查。

## 方案与边界

采用现有组件内的渐进优化：共享 QuotaUsageCard、原托盘窗口、原 Dashboard、原分享弹窗和原备份 API。另建独立页面会重复状态和入口；替换整个界面会扩大回归范围，因此本次不采用。以下细节是实现选择，不代表用户逐项指定。

1. **关注与身份**：每个额度卡可保存一个重点窗口（默认自动）；选择只影响主显示，不屏蔽风险、其他窗口或通知。多账号继续使用卡片 ID 隔离，卡片和详情显示现有 profile 标签及匿名账号标识。过期/未登录读数提供适用的复制登录命令或操作说明；不自动登录、不切换账号、不读取新的凭据。
2. **额度信息层次**：同一窗口按「名称与剩余量 → 进度 → 重置时间/风险」阅读。正常服务组件默认折叠，未知/过期不能当作正常，实际故障保持可见。数据来源等低频依据进入原生折叠区，全部信息保留。
3. **提醒定位**：额度提醒携带具体卡片 ID、窗口 ID 和已验证匿名账号引用；系统通知点击后核对账号身份，再显示原额度面板并打开对应详情、定位窗口。同账号展示去重可映射，换号或缺证据只显示面板与无法定位提示。重置与阈值去重规则不变。状态短句明确窗口，重复点击仍能重新定位；不存在的窗口给出提示并保留全部详情。
4. **浮窗摘要**：在原固定/托盘面板增加可见的「摘要/完整」切换并持久化。摘要每服务显示重点或自动风险窗口，所有服务和详情入口可达。保持固定、拖动、位置夹回、Escape、失焦和刷新行为。打开详情时保证足够窗口空间。
5. **总览快速查看**：增加持久化的「快速查看/完整分析」切换。快速查看复用原费用与 Token 主指标、额度和洞察，保留日期/Agent 筛选和完整分析入口；完整模式保留热力图、会话、输入输出、模型与项目分析。未知和部分计价口径沿用原组件。
6. **分享表达**：原详细卡片保留，增加 Token/费用主指标版式，使用真实累计 Token 趋势，增加 1:1、4:5、9:16 画幅和署名及复制配文。原 2:3 画幅、模板、背景编辑、下载、复制继续可用。预览与导出使用相同布局参数和尺寸；费用保持估算含义，数量遵守已有单位设置。单日/空数据不得伪造曲线。
7. **备份恢复**：校验后显示实际统计覆盖、采集来源、文件类别和数量；不将配置起点当作覆盖日期，不将备份与当前差值宣称为已去重增量。恢复可先由服务端持久保存当前实例保护快照；保护失败时不创建目标。恢复仍到新目录、不覆盖、不切换当前实例，显示保护与恢复各自结果。旧 v1 文件和原 API 调用仍可用。

## 共通约束

- Dashboard 与 Desktop 的共享组件直接复用，独立副本一起更新；新增共享样式登记 Desktop `@source`。
- 文案覆盖 zh-CN/en/ja/ko，复用 FilterMenu、HeroUI 和现有数字格式化入口。
- WCAG 2.2 AA 作为本次工程基线，实际验证键盘、关闭和焦点恢复、窄屏及长标签；不宣称全站认证。
- 在隔离 worktree 开发与运行，不改其他会话服务或正式数据；合成数据用于恢复/通知/账号测试。
- 本次不增加 Claude 金额采集、主动账号切换、Codex 重置兑换或原始日志合并恢复。
