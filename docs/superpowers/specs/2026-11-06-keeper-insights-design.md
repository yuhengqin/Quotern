# Keeper 借鉴：个人用量诊断与本地数据管理

用户要求在新分支和 worktree 完成上轮建议，并以 Chrome / Desktop 实际页面验收。范围为额度历史详情、性能分析、用户价格覆盖、本地备份及恢复；保留已有会话、价格比较、额度预测和设置能力。

## 设计选择

沿用 Quotern 的本机采集和 HTTP / IPC 契约。相比接入 CPA 服务端或另建请求数据库，复用已有原始响应证据、额度历史与定价事实能交付可核验的个人功能。代理凭证管理、完整请求成功率、逐 Token 速度和团队权限不在本次范围。

- **性能分析**：独立 `/performance` 页面，选择期间、Agent、模型及项目；从去重后的原始有效证据计算首字时间 P50/P95、按采样耗时加权的估算输出速度、样本数量及每日趋势。按 Agent / 模型 / 项目比较；最近样本可回到对应会话。Codex 首字值是回合记录，速度是现有筛选规则下的估算样本，两者不强行配对。没有样本为未知，不从会话均值推算分位数或成功率。
- **额度历史**：从现有额度详情按需打开；按窗口、实际 reset 和连续观察分组，保留首末观察、最后已用百分比和趋势。新增点保存可信时长和公开账号引用。旧点不倒推真实周期起点；回拨、未知 reset、账号缺失均明确表达。仅同服务、订阅模式、公开账号引用匹配时，按真实事件时间关联观察区间内的本机用量。跨设备消耗不可归因，功能池不能显示虚构的兑换率。
- **手动价格**：在价格页管理独立的本地基础费率，四项 Token 单价以 USD / 1M 为输入，空项继承、零为明确免费；可删除恢复当前参考表。按明确模型 ID 生效，不将用户条目加入模糊搜索。既有上下文、档位规则仍生效，来源上报金额保持优先。保存后刷新估算和缓存；展示影响提示及当前覆盖，远程价格刷新不得污染手动层。
- **备份与恢复**：设置提供创建、校验和恢复到新目录；CLI 同样支持 create / verify / restore。版本化备份包含规范化用量、会话、游标、安全配置字段、成就、额度历史和手动价格；排除凭据、设备身份、日志、锁和可重建缓存。同步与快照以同一数据事务锁互斥；文件清单、长度、SHA-256 和路径白名单校验全部通过后恢复。目标必须是新目录，原数据保留。恢复不自动切换运行中的实例；同机续采保留游标，跨机迁移不承诺外部 Agent 文件身份不变。

## 交互和约束

两端共用业务页面，transport 注入保留 Desktop IPC。筛选复用 FilterMenu，帮助复用 HelpPopover，表单与弹层沿用 HeroUI 3.2.4。Token 和费用复用已登记格式化入口，保存/读取错误靠近操作且可重试。四语言文案随功能模块注册。只在本机可信来源允许价格和备份操作，演示端服务端强制只读。

## 验收

核心测试覆盖原始分位数与重复/fork 样本、有效零与缺失值、真实时间边界、额度账号隔离、价格继承/恢复/规则与缓存失效、备份损坏/路径穿越/目标冲突/与同步互斥。运行 Core/CLI/两端类型检查和相关测试、完整构建，再用隔离数据启动 Chrome 与 Desktop 检查主路径、错误、键盘、窄屏、语言和 Token 单位切换。合成验收数据明确标识，正式数据不写入。
