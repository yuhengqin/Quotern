# 热力图图例

用户已确认按截图审查建议优化，并要求 Dashboard / Desktop 一致。

- 默认显示「每日 Token 用量」、少／多和现有五档主题色；辅助文字使用 12px。
- 宽屏左侧保留累计活跃及成就入口，右侧放图例；窄屏自然换行。
- 复用 HelpPopover，按需说明灰色为无用量记录、当前来源范围下的相对分档、实际 Token 分界和统计时区；Enter/Space 可打开，Escape 关闭并返回触发器。
- 分界数字遵循已有 Token 单位偏好并标明近似值；舍入后重合的区间使用「约某用量附近」，不以缩写值拼接精确不等式。没有活跃日不显示虚构范围，重复阈值不生成空区间。
- 保留原有日期选择、每日详情、来源筛选与成就跳转，不改变统计和颜色算法。

采用一个共享 ActivityHeatmapLegend，两端独立 ActivityHeatmap 传入相同类型的阈值及 footer 内容；比维护两套图例更能防止差异，复用整个热力图则会扩大无关范围。
